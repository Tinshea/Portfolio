# Portfolio — Personal Developer Portfolio

> Personal project by Malek Bouzarkouna

A personal portfolio website showcasing projects, experiences, skills, and a blog. Built with TypeScript and modern frontend tooling for a performant, accessible, and maintainable web presence.

🌐 **Live:** [malekbouzarkouna.com](https://www.malekbouzarkouna.com)

## 🛠️ Tech Stack

- **Core Technologies**: TypeScript, React (or Next.js)
- **Tools & Environment**: npm / yarn, ESLint, Prettier

## 📦 Installation & Setup

### Prerequisites

- Node.js 18+
- npm or yarn

### Instructions

```bash
# 1. Clone the repository
git clone https://github.com/Tinshea/Portfolio.git
cd Portfolio

# 2. Install dependencies
npm install

# 3. Run in development mode
npm run dev

# 4. Build for production
npm run build
```

## ✨ Sections

- **Projects** — showcase of university and personal projects
- **Experience** — professional and academic background
- **Skills** — tech stack and competencies
- **Blog** — technical articles and write-ups
